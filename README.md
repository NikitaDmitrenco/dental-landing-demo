# Dentiva — демонстрационный лендинг

Адаптивный одностраничный сайт вымышленной стоматологической клиники на Astro, TypeScript и Tailwind CSS. Генерирует статические файлы; сервер, база данных и Manus-hosting не используются.

> Демонстрационный проект. Клиника, специалисты, цены и отзывы вымышлены.

## Локальная разработка

Требуется Node.js 22 или новее и npm.

```bash
npm ci
npm run dev
npm run check
npm run build
npm run preview
```

Сборка находится в `dist/`. Для проверки настроек подпапки GitHub Pages используется `base: '/dental-landing-demo'` в `astro.config.mjs`; Astro применяет base к ресурсам из `public/`.

## GitHub Pages

Astro настроен на `https://nikitadmitrenco.github.io/dental-landing-demo/`. Репозиторий должен называться `dental-landing-demo` в аккаунте `NikitaDmitrenco`. В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow `.github/workflows/deploy.yml` запускает `npm ci`, `npm run build` и официальный Pages deploy при push в `main`, а также вручную через **Actions → Deploy to GitHub Pages → Run workflow**. В репозитории необходимы стандартные Actions-разрешения на чтение кода и публикацию Pages; workflow задаёт `contents: read`, `pages: write`, `id-token: write` и environment `github-pages`.

После первого успешного workflow сайт доступен по ссылке выше. Если имя владельца или репозитория меняется, измените `site` и `base` в `astro.config.mjs` соответственно.

## Демонстрационная форма и будущий обработчик

Форма проверяет имя и телефон в браузере. Сейчас `src/lib/submit-appointment.ts` — отдельная точка интеграции в безопасном demo-режиме: введённые данные не отправляются и не сохраняются. Успешная проверка не является подтверждением записи.

Чтобы подключить реальный приём заявок, замените реализацию `submitAppointment` на `fetch` к своему HTTPS API и показывайте подтверждение реальной отправки только после успешного ответа обработчика. Обрабатывайте ошибки сети/сервера без потери введённых данных. Храните ключи и токены только на сервере/в менеджере секретов; никогда не помещайте их в клиентский bundle или `PUBLIC_*` переменные. Сначала настройте защиту endpoint от спама и политику обработки персональных данных. Этот репозиторий не содержит backend и не отправляет PII.

## Фото и лицензии

Изображения в `public/images/` созданы генерацией изображений специально для демонстрационного макета и сохранены локально; внешняя лицензия/авторское фото не использовались. Промпты: интерьер современной светлой стоматологической клиники без логотипа и фото консультации врача с пациентом. Шрифты DM Sans и Manrope загружаются с Google Fonts; при необходимости полностью офлайн-режима замените их на локально размещённые файлы шрифтов с подходящей лицензией.

## Структура

- `src/data/services.ts`, `reviews.ts`, `contacts.ts` — данные страницы.
- `src/components/` — шапка, футер и окно записи.
- `src/lib/submit-appointment.ts` — модуль отправки формы (демо-режим).
- `src/styles/global.css` — адаптивная дизайн-система, Tailwind CSS и доступные состояния.
- `public/images/` — локальные визуальные ресурсы.
