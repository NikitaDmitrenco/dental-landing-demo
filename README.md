# Dentiva — демонстрационный лендинг

Статический одностраничный сайт вымышленной стоматологической клиники на Astro, TypeScript и Tailwind CSS.

> Демонстрационный проект. Клиника, специалисты, цены и отзывы вымышлены.

## Запуск

Требуются Node.js 22+ и npm. Выполните `npm ci`, затем `npm run dev`. Для production используйте `npm run build`; результат будет в `dist/`.

## GitHub Pages

Проект настроен на адрес `https://nikitadmitrenco.github.io/dental-landing-demo/`. Workflow в `.github/workflows/deploy.yml` собирает и публикует сайт при push в `main` и вручную из вкладки Actions.

## Форма

Форма работает в демонстрационном режиме: проверяет поля, но не отправляет и не сохраняет данные. Подключение реального обработчика описано в исходном README.
